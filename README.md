\# Photo Gallery



Professional photo gallery hosted on Cloudflare Pages with R2 storage.



\## Quick Commands



\- `npm run dev` - Start development server

\- `npm run build` - Build for production

\- `npm run generate` - Generate albums.json from photos folder



\## R2 Bucket URL



https://pub-YOUR-ID-HERE.r2.dev
